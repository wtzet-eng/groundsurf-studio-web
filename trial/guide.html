GroundSurf Studio

Getting started

  1. Open Studio or download the single HTML file and open it locally. The offline file needs no local server.
  2. From Projects, open a synthetic project ZIP. For your own work, use the borehole CSV importer and confirm the coordinate system, units and vertical datum from your source.
  3. Open Named horizons in the Explorer. Choose the logged top or base, pick contacts, review conflicts, and save the interpretation.
  4. Generate a surface definition only after reviewing interpolation assumptions. Rebuild saved horizons in 3D. Use Save complete project to keep the source observations and interpretations together.

What the project ZIP saves

Borehole sources, section images, named horizons, reviewed ties, surface definitions and supported time–depth records. Rebuild surfaces from their definitions. Original SEG-Y stays separate and can be relinked against its stored file identity. Export supported property ensembles and geometry uncertainty results separately. Grid meshes and the full numerical workspace require separate handling.

Scientific scope

Time–depth conversion uses one user-defined velocity and rejects picks outside the declared coverage. Geometry uncertainty is a bounded preview. Consult the methods before interpreting either result.
