LOCAL BY DESIGN

Privacy and your geological data.

The beta's core modelling functions run inside your browser. GroundSurf Studio does not require an account or upload your borehole CSVs and project ZIPs to a GroundSurf server.

How the application handles files

When you open the downloadable HTML file locally, its bundled code runs in your browser. You explicitly select source files to import and you choose when to save a complete project ZIP. The app's restrictive Content Security Policy blocks outgoing network connections from the bundled Studio application.

When you open Studio on the public website, your browser downloads the application HTML from static hosting. After it is loaded, geology calculations are performed locally. The hosted app's network policy is designed to prevent application-initiated requests.

About the website

This website is statically hosted using GitHub Pages. It does not include Google Analytics, advertising trackers, third-party fonts or external JavaScript libraries. Static hosting can still produce routine network request metadata or access logs controlled by the hosting provider. Visiting links to external sites (such as GitHub Issues or GroundSurf Site Intelligence) is subject to those sites' own policies.

Your responsibility

Imported borehole coordinates and geology may be confidential or commercially sensitive. Keep complete project ZIPs in a suitable location on your own computer. Do not attach private datasets to public GitHub issue reports. Exported files remain in your control; Studio does not guarantee that data outside the app is encrypted.

Limits of the beta

Studio is experimental geological interpretation software. It does not independently validate survey coordinate systems, geology, strata thickness or source attribution. An interpreted surface should not be treated as measured ground conditions.

For issues or questions, use the public feedback tracker.
