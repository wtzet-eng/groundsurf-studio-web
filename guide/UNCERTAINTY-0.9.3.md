# GroundSurf Studio 0.9.3 — conditional ensemble uncertainty

Build a numerical grid, run SGSIM or SISIM with at least two realizations, and keep the run in Realisations. Alternatively reopen a compatible realisation archive in the offline browser. Select the saved run and expand Uncertainty. Choose a statistic and Calculate uncertainty map. Use the existing Z slice control to inspect the map or export the uncertainty ZIP (world XYZ cell-centre CSV and metadata). No new solver is needed to calculate these statistics.

For continuous ensembles: mean, population standard deviation (denominator n), non-exceedance percentiles P10/P50/P90 (linear interpolation at (n-1)p), P90 minus P10, empirical frequency strictly above a user threshold. For categorical ensembles: category occurrence frequency and disagreement (100 percent minus the most frequent category's frequency). No arithmetic averages of category codes. Frequencies and disagreement always use a 0–100 percent colour scale. At each active cell, all realizations must be informed; otherwise the result is missing, never zero. Fault-review and ambiguous cells are not included. Ordinary kriging estimate and normalized variance are not a stochastic ensemble.

Nearest conditioning sample distance in metres is an additional support diagnostic, not a calibrated uncertainty measure or recommendation for a particular investigation location. It uses Euclidean distances to the selected run's conditioning samples and only the complete-case model support. No spatial optimization or expected information gain is performed.

Every map is conditional on a single saved run, fixed grid, observations, and model assumptions. No pooling of different runs, no uncertainty in the geological geometry, no calibration against unseen data, and no risk or engineering certification. The native preview has at most ten realizations per run: empirical frequencies are coarse (10 percentage points at ten), and tail percentiles are particularly unstable. Zero simulated spread does not prove zero real-world uncertainty. A threshold probability is an empirical ensemble frequency, not a verified chance of an actual event.

The export retains grid identity, run ID, worker hash, settings, units, statistic, parameter, ensemble size and conventions. Keep the original realisation archive and project ZIP for reproducibility; maps are derived display objects, not new measurements or permanent project ZIP fields. Recompute them from the saved run.
