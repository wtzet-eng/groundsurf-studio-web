THE FIELD GUIDE · PUBLIC BETA 0.7.5

Start with the evidence.

GroundSurf Studio is a local-first workbench for looking at borehole logs, drawing tentative correlations and examining conceptual 3D geology. You can begin in your browser without installing software.

Open Studio ↗Download offline ↓

1 · Open Studio and explore real boreholes

  1. Choose Open Studio, or download the HTML and open the file locally in a current Firefox or Chromium browser.
  2. Inside Studio, choose Explore real Stockholm logs · CC0. This includes 14 real reported SGU boreholes/probes and 100 logged intervals from a Swedish public-domain dataset.
  3. Rotate the observed 3D borehole columns. Inspect logged depths and material descriptions. These are reported source observations, not a verified geotechnical site model.

Example records come from the Geological Survey of Sweden. Source attribution and coordinate-reference limitations are preserved within the application. The selected 14-well subset is CC0; it is not an SGU-endorsed model.

2 · Correlate contacts with your mouse

  1. Select Boreholes to open the geological section.
  2. Try the Projection X/Y, Vertical exaggeration, Horizontal zoom and Borehole spacing controls.
  3. For rapid interpretation, choose Draw correlations with mouse, enter an interpreter name once and acknowledge that the ties are provisional.
  4. Click a logged interval in one borehole, then another. Inspect the dashed selection preview and click Add proposed tie to record your hypothesis.
  5. Enable Continue from B to connect another borehole with fewer clicks. Use Undo last tie to record a reversal if a pick was wrong.

Equal spacing is schematic. It separates borehole columns which overlap in a simple X/Y projection. Do not calculate real horizontal distances, gradients or layer dips from the equally spaced view.

3 · Compare interpreted surfaces

The Manual geological interpretation tools let you build proposed conceptual surfaces from explicitly chosen, source-bound contacts. To understand surface quality checks without pretending the Swedish records establish a continuous geological horizon, start with Try synthetic borehole logs.

Once you have two separate reviewed surface proposals, choose Compare saved surfaces in 3D. Pick an intended upper/lower order and run Geological Quality Check. This highlights mathematical crossings, inverted order and missing coverage.

4 · Calculate conceptual thickness

Within the geometric quality panel, choose Calculate thickness. Studio evaluates only overlapping triangle areas with a positive, ordered separation. Crossed, reversed, touching and unsupported regions are excluded, not guessed.

Not engineering evidence: A mathematically valid separation between two interpreted surfaces is not proof that a real layer or its calculated volume exists. Do not use conceptual thickness or volumes as measured site data, construction quantities, reserves or independent geological certification.

5 · Save, close, reopen

Choose Projects → Save complete project. Studio packages the original borehole CSV, source metadata and the interpretation history into one ZIP. It preserves the original borehole CSV bytes instead of rewriting them as inferred geology.

Later, choose Open complete GroundSurf Studio project ZIP. Rebuild conceptual 3D interpretations explicitly when desired; Studio does not silently certify or automatically regenerate saved visual conclusions.

Browser support and limitations

Version 0.7.5 public beta has been tested as an offline HTML file in Firefox and Chromium on Ubuntu. Windows and macOS are intended targets but need independent runtime validation. Some 3D features require WebGL support. The public launch is experimental and does not include a desktop QGIS/ParaView plugin bridge.

Help improve GroundSurf Studio

Report usability problems, compatibility issues or feature ideas at GroundSurf Studio public beta feedback. Please do not upload confidential borehole data, private property coordinates or client documents into public issue reports.
