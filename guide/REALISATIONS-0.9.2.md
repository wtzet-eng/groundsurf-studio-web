# GroundSurf Studio 0.9.2 — realisation manager

In the desktop edition, build a numerical grid and run native geostatistics. Name the run and select Keep in realisation manager. The library holds up to eight named runs with a combined limit of one million cell-property slots. Ordinary kriging estimates and normalized variance are separate outputs, not stochastic realizations. SGSIM and SISIM runs contain individual conditional realizations.

Open Geological objects > Realisations. Select a saved run and result, or use Next realisation. For continuous simulations the shared colour scale spans the run's minimum and maximum across all realizations, rather than automatically stretching each image. SISIM uses a discrete palette keyed to the run's conditioning categories; codes are not continuous magnitudes. The 3D grid and horizontal slice control remain available. Hide property returns to geological colouring. Runs can be renamed or removed independently of the geological observations. Closing the object controls does not remove saved runs.

Export realisation archive writes a separate JSON file with named runs, full numerical properties, normalized conditioning records, run settings, timestamp and native worker SHA-256. Save the complete geological project ZIP separately. Reopening: open the original geological project, rebuild horizons, layers and the exact same numerical grid (including displacement scenario, dimensions and geological interpretation), then open the archive under Realisations. This works in the offline browser without native workers. The SHA-256 identity uses the project ID, source hash, complete grid and saved proposals/framework/faults, with canonical object key ordering. The archive importer checks identity, sample domain, result dimensions, valid values and category codes and refuses non-active results. It is not proof of authenticity or a digital signature of the result values.

The in-memory library holds one grid identity at a time; other grid configurations hide its results and offer export of the previous library. Replacing that library needs confirmation. Archives merge atomically and reject duplicate names/IDs. There is no automatic save; export before closing the application or opening another project. The 16 MB archive limit and 2 MB normalized conditioning text per run keep this preview bounded. No mean, percentile, probability map or uncertainty calibration yet. These are property runs on a fixed conceptual geometry, not alternative geological geometries.

The Ubuntu amd64 desktop uses the same optional, separately distributed hash-checked Workbench workers as 0.9.1. Portable HTML supports inspection and archive reloading but not execution of native algorithms. See NATIVE-GEOSTATISTICS-0.9.1.md.
