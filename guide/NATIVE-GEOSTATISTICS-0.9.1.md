# GroundSurf Studio 0.9.1 — native geostatistics preview

The Ubuntu amd64 desktop can call separately installed SGeMS Workbench 0.4.5 GsTL workers. The portable HTML continues to support offline SGeMS GSLIB exchange but cannot execute native binaries. No Wine, network, or full SGeMS desktop runtime is necessary. No third-party executable is redistributed in Studio.

## Worker setup
From a trusted SGeMS Workbench 0.4.5 ZIP, extract only engine/ordinary-linux-x86_64, engine/simulate-linux-x86_64 and engine/LICENSE-GsTL under ~/.local/share/groundsurf-studio/gstl-workbench-0.4.5/ (the ZIP paths begin sgems_export/). Mark the two workers executable. Studio checks the exact SHA-256 of the known 0.4.5 binaries before every run. For explicitly trusted alternative builds, set GROUNDSURF_GSTL_ORDINARY and GROUNDSURF_GSTL_ORDINARY_SHA256, or GROUNDSURF_GSTL_SIMULATE and GROUNDSURF_GSTL_SIMULATE_SHA256, in the desktop launch environment. A renderer request cannot choose an executable or inject shell commands. Keep the original Workbench ZIP and license notices. The integration uses GsTL, software developed by Stanford University and its contributors.

## Workflow
Build a numerical geological grid; open Geological objects > Native geostatistics · GsTL. Select one active geological unit, and one side if a displacement scenario is active. Load a GSLIB XYZ point set with measured numeric conditioning property. Select world or local coordinates, units, source and spherical range in metres. Confirm compatible coordinates and datum. Every informed sample must be in the selected active domain; conflicting duplicates are rejected, identical duplicates collapsed. No lithology-to-property assumptions. The worker uses the selected cell centres within the specified distance of an observation; missing and inactive cells are excluded. This is a conservative centre-sampled mask, not a hydraulic connectivity model. On an undisplaced grid, a fault is not an automatic barrier. Verify the sample selection and range scientifically.

Ordinary kriging: spherical covariance with zero nugget, unit sill, up to 16 nearest observations; variance is normalized and not calibrated physical uncertainty. The nearest-observation support cutoff does not impose a hard cutoff on every ordinary kriging neighbour. SGSIM: empirical midrank normal scores and linear back-transform with clamped tails; seeded GsTL sequential simulation, up to 16 neighbours within range. SISIM: integer categories remapped to contiguous codes and back, shared indicator covariance, empirical proportions. Up to ten realizations per job, 30,000 simulated values, 2,000 samples, 10,000 targets and five million sample/target pairs. Native process time limit 30 seconds. These are simplified isotropic experimental models, not full SGeMS algorithm parity or validated engineering designs.

Choose a result (estimate, normalized variance or individual realization) to colour the grid. Export native results ZIP contains local XYZ results.dat, normalized copy of the input conditioning.dat and model.json with settings, source, original frame and worker hash. Results remain transient; changing the underlying grid invalidates them; closing the object controls can discard the run selection. Export before leaving. The complete project ZIP does not yet persist native property realizations. Keep source data separately. No automatic variogram fit, anisotropy, full uncertainty analysis or simulation of flow.

## Installation
The experimental Ubuntu 24.04 amd64 .deb uses the existing package name groundsurf-studio and upgrades an older installed preview if installed. No installation is performed automatically. The installed package retains the Chromium sandbox helper and does not use --no-sandbox. Local development GUI automation may require a synthetic-only sandbox bypass; this is not an installation recommendation.
